Getting started with Spec Kit
The repository includes the templates, Bash scripts, workflow and Copilot skills generated by Specify CLI 1.0.13. To install that CLI on a machine with Git, Python 3.11+ and uv, run:

uv tool install 'specify-cli==1.0.13'
specify integration status
Run the status check from the cloned repository. The workshop setup chapter introduces the same workflow. In this version the agent selection flag is --integration.

Open the repository in VS Code with GitHub Copilot for Patti’s build. For Raphael’s Codex build, run the following in a separate private development checkout:

specify integration switch codex --integration-options="--skills"
specify integration status
Keep the agent switch in that checkout. The active feature is set in .specify/feature.json. Verify it with bash .specify/scripts/bash/check-prerequisites.sh --paths-only. Start with the constitution skill to agree on project principles, then use clarify on the shared feature spec. Run plan and tasks in each partner’s own build. Keep build code and prompts private until the comparison.
