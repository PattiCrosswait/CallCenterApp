## Getting started with Spec Kit

The repository includes the templates, Bash scripts, workflow and Copilot skills generated by Specify CLI 1.0.13. To install that CLI on a machine with Git, Python 3.11+ and uv, run:

```sh
uv tool install 'specify-cli==1.0.13'
specify integration status
```

Run the status check from the cloned repository. The [workshop setup chapter](https://roelantd.github.io/spec-kit-workshop/01-setup-prerequisites) introduces the same workflow. In this version the agent selection flag is `--integration`.

Open the repository in VS Code with GitHub Copilot for Patti’s build. For Raphael’s Codex build, run the following in a separate private development checkout:

```sh
specify integration switch codex --integration-options="--skills"
specify integration status
```

Keep the agent switch in that checkout. For the dashboard feature, use branch `001-call-center-dashboard` in each independent build so Spec Kit resolves the existing spec. Start with the constitution skill to agree on project principles, then use clarify on the shared feature spec. Run plan and tasks in each partner’s own build. Keep build code and prompts private until the comparison.
